# Decisions

Esta pasta é o registo explícito das decisões tomadas para a história.

**DECIDIDO** = base de trabalho estável.
**CANDIDATO** = proposta forte ainda sujeita a validação.
**WORKING** = solução operacional provisória.
**ABERTO** = ainda não escolhido.

Uma decisão nova que contradiga uma anterior deve registar a substituição e a razão.

`decisions/` regista o que decidimos.
`canon/` regista o que é verdade no mundo e a cronologia.
`planning/` transforma decisões em trama.
`research/` guarda evidência e investigação.
