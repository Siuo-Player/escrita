## Operating rule

At each scene, combine the prior end-state, persistent profiles, the dated calendar/schedule, knowledge gained on-page, and the scene-specific state below. Apply the ending delta to all later scenes. The ledger is deliberately more detailed than the prose: most facts guide dialogue and choices without being explained to the reader.

UNKNOWN is not a negative. If a character does not appear, their life still advances off-page, but do not invent a dramatic event merely to make the world feel alive. If a person speaks, promises something, possesses a relevant object, knows a private fact, or changes an outcome, record the cause/date of that state. When a beat requires an unnamed person, keep them an aggregate unless their individuality matters; if they matter, profile them before prose approval.

Core sources: Nathan's profile and knowledge/skill ledger; the first mobile-game design; the football roster; Alex/Haley/Claire secondary social circles; the Modern Family character state baselines; recurring schedules; and the Episode 1 scene-state ledger.

### Game state
- A small 2D C++ game provisionally titled Current. The prototype has grid/tile maps, player movement, a basic enemy archetype and patrol, A* baseline, a shared flow-field navigation layer, local steering and an early prediction/influence map.
- The game is a playable vertical slice, not finished/released. The working aim is conservative 2009 iPhone/iPod Touch class hardware; 20+ active guards stress-test the architecture. Never claim a measured frame rate unless a dated test records it.
- Known open issues from Episode 1: unnecessary updates/cache opportunities, a collision/steering defect, predictor overconfidence, and further device/performance verification. These are separate items; solving one does not solve all.
- Development setup must match the chosen implementation/toolchain. The project file discusses period-appropriate iOS development and its hardware requirements. Do not imply a public App Store release just because a build is playable.
