# Season 1 Character Episode Grids

Status: WORKING / operational continuity system
Updated: 2026-10-08

## Purpose

This document turns the recurring-schedule idea into an episode-level character grid.

The grid exists before scene writing. It answers four questions:

1. What is each recurring character doing during the episode?
2. Where are they likely to be?
3. Which relationships or private goals are active even when Nathan is absent?
4. Which character combinations can naturally produce a scene?

The grid is not a mandatory scene list.

A character may complete an activity off-page. A row can contain several possible scenes, while the final prose
may use none of them.

The authoritative principle is:

> First create the characters' continuous lives; then choose the scenes where those lives naturally overlap.

This avoids the feeling that characters teleport into place because an episode needs them.

## Episode 1 scene-selection rule

A final sequence should usually contain one active overlap and several off-page lives.

Example:

> Nathan leaves school → passes the pickup area → Claire is there because she is collecting Alex → brief
> exchange → Nathan continues home → Alex later mentions the new student at home.

The story does not need to show every step, but the grid makes every step possible.

# Scene assembly method

## Layer 1 — private schedule

Before writing, assign every recurring character:

- morning location;
- school/work location;
- afternoon activity;
- evening activity;
- personal goal;
- at least one likely location overlap.

## Layer 2 — episode thread

For each date, mark:

- what changes;
- what continues;
- what can be skipped.

## Layer 3 — intersection

Only after the above is defined do we choose scenes.

A scene is strongest when the characters would have been there anyway.

### Preferred intersection types

**Natural overlap**

Two people independently attend the same place.

**Task overlap**

One person's routine creates a reason for another to be present.

**Consequence overlap**

An event happens off-page and its effect reaches another character later.

**Transit overlap**

A character is seen while moving between routine locations.

**Domestic overlap**

A family member appears because the household is physically sharing the same space.

## Characters can be off-page

The grid explicitly permits:

- Claire is at the supermarket without a supermarket scene;
- Alex practices cello without showing the whole practice;
- Phil is at a client appointment without naming the client;
- Haley is with friends without turning it into a subplot.

These facts still matter because they constrain later scenes.

## Continuity test

Before accepting a scene, ask:

1. Where did each character come from?
2. Why are they here now?
3. What did they just finish doing?
4. What will they probably do afterward?
5. Has anything in this scene changed a later schedule?
6. Could the same scene happen without the author forcing a coincidence?

The best scenes normally pass all six.

## Relationship-memory rule

Each contact should leave one or more tiny memory traces.

Examples:

- Claire remembers Nathan's face.
- Phil remembers that Nathan plays football.
- Haley remembers that the new kid is quiet.
- Alex remembers the exact book conversation.
- Nathan remembers all four encounters far more vividly than they do.

The mismatch in memory depth should be used carefully. It creates asymmetry without requiring exposition.

## Prop and location rule

The character grid also serves as a provenance map.

When a later scene needs:

- a football;
- cello equipment;
- school supplies;
- a household tool;
- a toy;
- a computer accessory;
- groceries;
- a book;

the planning layer should know where it came from.

Not every object needs a scene explaining its origin.

Important recurring objects should not materialize precisely when convenient.

## Compression rule

The final prose does not need to narrate the grid.

A month can be covered by a handful of scenes because the missing days remain accounted for.

The reader should feel:

Life continued while the camera was elsewhere.

That is the goal of the system.
